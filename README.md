# GeoDuel für Android

[**GeoDuel v0.1.0 herunterladen (APK, ca. 5 MB)**](https://github.com/flegik/geo-duel/raw/refs/heads/main/GeoDuel-v0.1.0.apk)

Auf beiden Android-Handys dieselbe APK installieren. Einmal einen Spielernamen wählen, dann erstellt einer ein Duell und der andere tritt mit dem vierstelligen Raumcode bei. Beide müssen bereit sein; der Host startet das Duell.

Keine Registrierung, kein Passwort und kein Supabase-Konto für Spieler. Internet ist für gemeinsame Duelle erforderlich. Supabase betreibt den gemeinsamen Spielserver im Hintergrund.

Version: 0.1.0 · Paket: `de.flegik.geoduel` · Android 7.0 oder neuer.

Die APK ist als Release mit APK Signature Scheme v2/v3 signiert. Android-Build, Android-Lint, 31 automatisierte Prüfungen und echte Online-Duelle sind bestanden. Ein tatsächlicher Smartphone-Test steht noch aus.

Prüfsumme: [SHA-256](GeoDuel-v0.1.0.sha256).

Normale Updates mit derselben Signatur behalten die App-Daten. Deinstallation oder Löschen der App-Daten kann den Gastzugang entfernen.

Dieses Repository enthält nur die fertige APK, Prüfsumme und Downloadhinweise. Private Fragenbank, Zugangsschlüssel und Signierschlüssel werden hier nicht veröffentlicht.
